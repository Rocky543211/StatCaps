Import virtue ranks into StatCaps

This helper runs locally in your browser on Windows and Linux. It does not upload files, contact a server or modify your saved plugin data.

Select your Companion character configuration

In LOTRO Companion, import your character with Current Gear selected. Choose the XML for that imported configuration in Companion's character data folder, not summary.xml, deedsStatus.xml or the separate virtue-XP status file.

No file selected.

Copy and review in game

Open Virtues → All virtue ranks → Import from Companion in StatCaps. Paste the output, select Review imported ranks, check the character and values, then select Save all virtue ranks.

Imports all 21 earned ranks, including untrained ranks of zero. Does not change your equipped virtue selection. A simulated or old Companion configuration may not match your current character.
